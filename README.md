# The Lab Manual

**This guide is currently ***under construction*** and will (hopefully) contain a wealth of knowledge to help the fledgling scientist get started in the wet lab**

## Purpose

The goal of this GitHub repo is to have a living document that is easily editable by members of the scientific community. Currently, I only have one section of content on molecular cloning (specifically traditional restriction/ligation cloning and Golden Gate, with more cloning techniques on the way). I am currently writing some more articles on bacterial and mammalian cell culture.

## AI usage

I use Claude for scaffolding the website builds and for proofreading, but none of the prose in this repository is AI generated. That means that I (or any contributor) write the text that the users actually read. If you are interested in contributing, I ask that you refrain from using Claude, or any other AI agent from generating text that is published to this repository. Proofreading of text is fine, but make sure that you are the person doing the typing.
